Bangkitkan round key K[0] ... K[15] dari master key.

Master key (128 bit) dipecah jadi dua 64 bit (a dan b). Tiap round i:

a = rotl(a, 13) + PHI * (i + 1) // mod 2^64
a = sbox64(a)
b ^= rotl(a, 29)
swap(a, b)
K_i = a xor b

Konstanta PHI (0x9E3779B97F4A7C15, golden ratio) dikali nomor round, jadi tiap round key beda meskipun master key-nya berpola (misal semua nol).

Parameters
[in]aSeparuh kiri master key (8 byte pertama), 64 bit.
[in]bSeparuh kanan master key (8 byte terakhir), 64 bit.
[out]rkArray ROUNDS elemen, diisi K_0 ... K_15.
Note
Hanya dipanggil sekali per kunci (di constructor CustomCipher), bukan per blok.

Contoh penggunaan:

uint64_t rk[ROUNDS];
key_schedule(0x0123456789ABCDEFULL, 0xFEDCBA9876543210ULL, rk);
