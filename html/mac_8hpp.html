void cmac_detail::dbl ( const uint8_t in[16],
uint8_t out[16] )

Operasi doubling dalam medan GF(2^128) pada blok 16-byte big-endian.

Menggeser seluruh blok 128 bit ke kiri sebesar 1 bit secara branch-free. Jika MSB bernilai 1, byte terakhir (byte 15) di-XOR dengan konstanta Rb = 0x87.

[out]outBlok hasil doubling, 16 byte.
