Dekripsi data menggunakan mode Cipher Block Chaining (CBC).

Formula: P_0 = D(C_0) ^ IV, P_i = D(C_i) ^ C_{i-1} untuk i >= 1. Mendukung akselerasi OpenMP multi-thread karena seluruh blok ciphertext sudah tersedia.

Parameters
[in]cipherObjek block cipher yang digunakan.
[in]ivInisialisasi vektor (IV), panjang BLOCK_SIZE byte.
[in]inData ciphertext (kelipatan BLOCK_SIZE).
Returns
util::Bytes Data plaintext hasil dekripsi (masih berpadding).
Exceptions
std::invalid_argumentjika in bukan kelipatan BLOCK_SIZE atau iv bernilai nullptr saat in tidak kosong.

◆ ctr_at()

void modes::ctr_at ( const uint8_t iv[BLOCK_SIZE],
uint64_t i,
uint8_t out[BLOCK_SIZE] )

Menghitung nilai counter 128-bit big-endian pada indeks blok ke-i langsung: (IV + i) mod 2^128.

Fungsi ini mendukung carry 128-bit penuh dan wrap-around dari 0xFF..FF ke 0x00..00. Digunakan baik pada eksekusi serial maupun paralelisasi multi-thread OpenMP agar setiap thread dapat menghitung counter blok tanpa iterasi dari awal.

Parameters
[in]ivNilai IV / counter awal (16 byte).
[in]iIndeks blok (offset penambahan counter 64-bit).
[out]outBuffer keluaran hasil (16 byte).
Exceptions
std::invalid_argumentjika iv atau out bernilai nullptr.
